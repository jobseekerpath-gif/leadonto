## 🆘 Troubleshooting

### "Build failed"
- Check `pnpm-lock.yaml` exists
- Ensure `package.json` scripts are correct
- Look at build logs in Railway dashboard

### "Port not assigned"
- Railway auto-assigns PORT
- Don't hardcode ports in code

### "Database connection failed"
- Check DATABASE_URL is correct
- PostgreSQL addon must be running
- Click "Generate" button in Railway if needed

### "Google login not working"
- Verify CLIENT_ID and CLIENT_SECRET
- Check callback URL matches Google Console
- Look at auth logs in Railway

### "CORS errors"
- Add APP_ORIGIN to environment
- Check configuredOrigins in `artifacts/api-server/src/app.ts`
